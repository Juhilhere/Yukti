### Install in three steps

1. Double-click **Yukti-Setup.exe**. If Windows shows “Windows protected your PC”, click **More info → Run anyway**.
2. Yukti opens and sets itself up: it downloads its AI once. Keep the window open. If the internet drops, it continues by itself.
3. Sign in. From now on Yukti works **without internet**.

| | |
|---|---|
| **Windows** | 10 or 11, 64-bit |
| **Memory** | 8 GB (16 GB recommended) |
| **Free disk space** | about 10 GB |
| **Graphics card** | not required. An NVIDIA card makes answers faster |
| **First download** | 2.7 GB, or 3.4 GB with an NVIDIA card (10–40 minutes). About 0.9 GB if the computer already has an AI model |

Problems? In Yukti: **Help → Report a problem**, or email **juhilprogramming@gmail.com**.

### What is new in {VERSION}

- **A smaller first download when the computer already has an AI model.** If a model Yukti can run is already there (for example one downloaded with LM Studio), Yukti uses it and does not download its own (2.4 GB less). Yukti's own model can still be added at any time: *Other options* on the setup screen, or by adding photos. On a computer without any model, nothing changes: Yukti downloads its own model and works exactly as before.

**Since 0.5.0**

- 📷 **Ask with a photo.** Photograph a pipe label, tag plate or nameplate. Yukti reads it and tells you what the line or equipment is from the plant's documents. It never guesses from the colour, and it points out rust and leaks.
- 🎙️ **Speak instead of typing.** Speak in English, Hindi or Kannada. The words appear in the question box so you can check them before sending.
- Both are optional add-ons: after installing, click **Add** on Yukti's home screen (photos about 800 MB, voice 0.3–1 GB).
- Company-level information (finances, leadership) is for top management only. A local journal records every problem with a reference number.

**Already using Yukti?** Download and run the new **Yukti-Setup.exe**, then click **Update now**. Your documents, chats and settings are kept.

The full list of changes is in the [changelog](https://github.com/{REPO}/blob/main/CHANGELOG.md).

### हिंदी

1. **Yukti-Setup.exe** डाउनलोड करें और उस पर डबल-क्लिक करें (अगर Windows चेतावनी दिखाए: **More info → Run anyway**)।
2. Yukti खुलेगा और खुद को तैयार करेगा। वह अपना AI एक बार डाउनलोड करेगा (2.7–3.4 GB)। विंडो खुली रखें।
3. साइन इन करें। इसके बाद Yukti **बिना इंटरनेट** के चलता है।

**इस संस्करण में नया:** अगर कंप्यूटर पर पहले से कोई AI मॉडल है (जैसे LM Studio से), तो Yukti उसी का उपयोग करता है और अपना मॉडल (2.4 GB) डाउनलोड नहीं करता। जिस कंप्यूटर पर कोई मॉडल नहीं है, वहाँ Yukti पहले की तरह अपना मॉडल डाउनलोड करता है।

**0.5.0 से:** 📷 फ़ोटो भेजकर सवाल पूछें (पाइप का लेबल, टैग प्लेट, नेमप्लेट) · 🎙️ टाइप करने की जगह बोलें (हिंदी, English, ಕನ್ನಡ)। ये दोनों वैकल्पिक हैं: इंस्टॉल के बाद Yukti की होम स्क्रीन पर **जोड़ें** दबाएँ।

### ಕನ್ನಡ

1. **Yukti-Setup.exe** ಡೌನ್‌ಲೋಡ್ ಮಾಡಿ ಅದರ ಮೇಲೆ ಡಬಲ್-ಕ್ಲಿಕ್ ಮಾಡಿ (Windows ಎಚ್ಚರಿಕೆ ತೋರಿಸಿದರೆ: **More info → Run anyway**).
2. Yukti ತೆರೆದು ತಾನೇ ಸಿದ್ಧವಾಗುತ್ತದೆ. ತನ್ನ AI ಅನ್ನು ಒಮ್ಮೆ ಡೌನ್‌ಲೋಡ್ ಮಾಡುತ್ತದೆ (2.7–3.4 GB). ವಿಂಡೋ ತೆರೆದಿಡಿ.
3. ಸೈನ್ ಇನ್ ಮಾಡಿ. ನಂತರ Yukti **ಇಂಟರ್ನೆಟ್ ಇಲ್ಲದೆ** ಕೆಲಸ ಮಾಡುತ್ತದೆ.

**ಈ ಆವೃತ್ತಿಯಲ್ಲಿ ಹೊಸದು:** ಕಂಪ್ಯೂಟರ್‌ನಲ್ಲಿ ಈಗಾಗಲೇ AI ಮಾದರಿ ಇದ್ದರೆ (ಉದಾ. LM Studio ನಿಂದ), Yukti ಅದನ್ನೇ ಬಳಸುತ್ತದೆ ಮತ್ತು ತನ್ನದೇ ಮಾದರಿಯನ್ನು (2.4 GB) ಡೌನ್‌ಲೋಡ್ ಮಾಡುವುದಿಲ್ಲ. ಯಾವುದೇ ಮಾದರಿ ಇಲ್ಲದ ಕಂಪ್ಯೂಟರ್‌ನಲ್ಲಿ Yukti ಮೊದಲಿನಂತೆಯೇ ತನ್ನ ಮಾದರಿಯನ್ನು ಡೌನ್‌ಲೋಡ್ ಮಾಡುತ್ತದೆ.

**0.5.0 ರಿಂದ:** 📷 ಫೋಟೋ ಕಳುಹಿಸಿ ಪ್ರಶ್ನೆ ಕೇಳಿ (ಪೈಪ್ ಲೇಬಲ್, ಟ್ಯಾಗ್ ಪ್ಲೇಟ್, ನೇಮ್‌ಪ್ಲೇಟ್) · 🎙️ ಟೈಪ್ ಮಾಡುವ ಬದಲು ಮಾತನಾಡಿ (ಕನ್ನಡ, हिंदी, English). ಇವೆರಡೂ ಐಚ್ಛಿಕ: ಅನುಸ್ಥಾಪನೆಯ ನಂತರ Yukti ಮುಖಪುಟದಲ್ಲಿ **ಸೇರಿಸಿ** ಒತ್ತಿ.
